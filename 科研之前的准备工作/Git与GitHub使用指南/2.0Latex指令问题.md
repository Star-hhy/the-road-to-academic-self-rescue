# Git与GitHub书写方式注意



## Latex公式

#### 1. 行内公式（文中穿插）—— 全网统一强制规范

**固定写法：\$\` 公式 \`\$**

优势：

- 彻底解决下划线 `_`、星号 `*` 被 Markdown 误解析的问题
- 深度学习公式大量带下标、粗体、符号，**100% 兼容 GitHub**
- 写法稳定、零翻车、不用转义

示例：

```
$`\boldsymbol{\hat{w}},\hat{b} = \text{argmin} L(\boldsymbol{w},b)`$
```

效果：$`\boldsymbol{\hat{w}},\hat{b} = \text{argmin} L(\boldsymbol{w},b)`$

#### 2. 块级公式（独立居中大公式）—— 统一换行写法

**固定写法：$$ 单独换行 $$**

模板：

```Plain
$$
公式内容
$$
```

示例：

```Plain
$$
\boldsymbol{\hat{w}},\hat{b}=\underset{\boldsymbol{w},b}{\text{argmin}} L(\boldsymbol{w},b)
$$
```

✅ 居中、清晰、标准学术排版

❌ 禁止：行内公式用 $$，块公式用 $` `$

### 二、关键避坑规则（你的笔记专用）

#### 1. GitHub 不支持

`\operatorname{}` 会报错、无法渲染

**统一替换为：\text{}**

例：`\text{argmin}`、`\text{argmax}`

####　2. 代码块内公式不渲染

被 ````python / ```md` 包裹的内容，**所有 $ 公式全部失效**。

公式必须写在**代码块外面**。

#### 3. 普通文本单独 \ 会被吞掉

只有在 `$` `$` 和 `$$ $$` 内部，反斜杠 \ 才是 LaTeX 命令。

普通文本里单独写`\boldsymbol` 直接失效。

### 三、全局统一总结（一句话背下来）

- **文中小公式：永远用 $\`  \`\$**
- **独立大公式：永远用 $$ 换行 $$**
- **算子一律用 \text{} 不用 \operatorname{}**

### 四、四大公式写法详解（可用/禁止 全覆盖）

汇总 GitHub 所有常见 Markdown 数学公式写法，明确**推荐用法、可用兼容、绝对禁止**三类规则，适配深度学习笔记编写场景。

#### 1、写法一：\$`公式`\$（全局首选、强制推荐）

**格式**：`$` LaTeX公式 `$`

**适用场景**：所有行内公式（嵌入正文句子中）

**核心优势**：

- 自带符号保护，彻底规避 `_`（下标）、`*`（乘号/斜体）被 Markdown 错误解析的问题
- GitHub 原生完美兼容，零渲染报错
- 无需手动转义特殊符号，适配绝大多数深度学习公式

**✅ 状态：最优推荐、统一规范写法**

#### 2、写法二：\$公式\$（普通行内公式）

**格式**：`$LaTeX公式$`

**适用场景**：无特殊符号、无下标、无星号的简单行内公式

**致命缺陷**：公式中含 `_`、`*` 时，会被 Markdown 识别为格式语法（斜体、下划线），直接打乱公式结构，渲染失效

**⚠️ 状态：可用但不推荐，极易翻车，禁止在复杂公式中使用**

#### 3、写法三：\$\$ 公式 \$\$（换行块级公式）

**格式**：单独换行书写，首尾双美元符各占一行

```Plain
$$
公式内容
$$
```

**适用场景**：独立展示的大公式、推导式、核心公式（需要居中、单独排版）

**优势**：GitHub 标准学术排版，自动居中、行距规范，适配所有复杂公式

**✅ 状态：块级公式唯一推荐写法**

#### 4、写法四：```math 代码块公式

**格式**：math 专属公式代码块

~~~Plain
```math
公式内容
```
~~~

**适用场景**：批量公式、长推导公式、需要区分代码与公式的场景

**缺陷**：GitHub 支持但排版紧凑，无默认居中效果，观感不如 `$$ $$` 规范

**⚠️ 状态：可用但不优先推荐，仅特殊场景备用**

### 五、严格禁止的写法（必避坑）

以下写法**一律禁止使用**，会直接渲染失败、格式错乱、显示异常：

- **禁止1：\`\$公式\$\`（反引号包裹美元公式）** ，反引号会强制固化源码，导致 GitHub 完全不解析 LaTeX 公式，直接原样显示代码文本
- **禁止2：\$\` 多行公式 \`\$** 行内专用语法不支持换行，强行写多行会直接排版错乱、渲染截断
- **禁止3：$$ 单行紧凑写法（不换行）** 错误格式：`$$\hat{y}=wx+b$$`，兼容性差，部分场景会丢失居中效果、公式挤压变形
- **禁止4：代码块（python/md）内写公式** ````python` / ````md` 普通代码块内的所有公式，全部失效无法渲染
- **禁止5：使用 \operatorname{} 算子** GitHub KaTeX 引擎不支持，会直接报错渲染失败，统一替换为 `\text{}`

### 六、最终极简执行标准

- 所有行内公式：只写 \$\` 公式 \`\$
- 所有独立块级公式：只写**换行版**`$$ 公式 $$`
- 杜绝所有禁止写法，不混用多种公式语法，全程统一规范

行内模板：\$\`x_{ij}, \boldsymbol{w}, \hat{y}\`\$

块级模板：

```Plain
$$
\hat{y} = \boldsymbol{w} \cdot \boldsymbol{x} + b
$$
```
